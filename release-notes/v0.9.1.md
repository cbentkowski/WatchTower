# WatchTower 0.9.1

WatchTower 0.9.1 is a container security patch for the 0.9.0 release.

## Security fixes

- Refresh Debian Bookworm's OpenSSL runtime packages to the security-fixed `3.0.22-1~deb12u1` release or a later compatible revision.
- Resolve the fixable OpenSSL findings CVE-2026-75803, CVE-2026-63076, CVE-2026-54874, CVE-2026-63072, CVE-2026-42767, and CVE-2026-63074 reported against the 0.9.0 image.
- Pull the current base image and rebuild package-install layers for every published image instead of restoring a potentially stale operating-system package layer from cache.

No WatchTower application behavior or configuration has changed in this patch.
