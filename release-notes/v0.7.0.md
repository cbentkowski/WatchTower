# WatchTower 0.7.0

Vantage makes delegated access understandable and testable without creating additional identity-provider users.

## Highlights

- Verify saved or proposed identity mappings and grants before saving them.
- See which grants contribute every effective application, workspace, feed, scan, and access-administration permission.
- Browse WatchTower through a server-enforced, read-only Permission Preview with a persistent exit banner.
- Delegate access-control work through the Access Administrator role without automatically granting operational or system-administrator permissions.
- Protect Access Administrator assignments so only a configured protected administrator can change them.
