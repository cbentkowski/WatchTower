# WatchTower 0.9.2

WatchTower 0.9.2 is a CPE mapping validation patch for the 0.9 release line.

## Fixed

- Accept valid canonical CPE components containing escaped punctuation when applications are created or updated.
- Support the NVD Notepad++ product component `notepad\+\+` without weakening validation of the complete CPE 2.3 name.

No configuration changes are required.
