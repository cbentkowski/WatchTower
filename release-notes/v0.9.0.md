# WatchTower 0.9.0

Resolve adds an accountable response workflow to vulnerability findings and safer inventory administration.

## Highlights

- Track each finding as New, Investigating, Remediation planned, Mitigated, Resolved, Risk accepted, Not affected, or False positive.
- Record assignees, due dates, notes, actors, timestamps, and expiring risk acceptances in persistent assessment history and audit logs.
- Reopen completed dispositions automatically when material vulnerability evidence changes or a temporary risk acceptance expires.
- Attach a plain external ticket reference or a validated HTTPS ticket link without requiring a ticketing-system integration.
- Review findings and application context in a wider, responsive application workspace with a dedicated response editor.
- Safely delete applications and workspaces through exact-name confirmation, server-side authorization, and automatic relationship cleanup while preserving finding history.
- Return stale browser sessions to sign-in after a server restart instead of leaving the interface in an error state.

## Operational improvements

- Organize runtime modules and browser assets under `src/` for a cleaner project layout.
- Build, scan, and publish containers only when application source or another image input changes.
- Harden untrusted vendor-feed markup handling and documentation validation.
