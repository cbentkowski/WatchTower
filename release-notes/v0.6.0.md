# Cartographer

Cartographer makes application mapping easier to configure and safer to trust.

## Highlights

- Replaced the application CPE fields with a dedicated vulnerability mapping dialog.
- Added advanced NVD CPE search across multiple fields, full CPE 2.3 parsing, pagination, and mapping warnings.
- Added product-level and exact-version mapping modes with validation for versions and qualifiers.
- Added live mapping tests against representative NVD vulnerability candidates before saving.
- Added searchable endoflife.date lifecycle mapping with application- and CPE-aware result ranking.
- Added lifecycle release previews, installed-version matching, maintenance state, and end-of-life details.
- Preserved manual lifecycle dates and source URLs for products that are not listed by endoflife.date.
- Migrated legacy mappings while retaining compatibility with existing application data.

## Validation

- Expanded automated coverage for CPE parsing, mapping behavior, lifecycle search, and release matching.
- Validated the mapping workflows against the live NVD and endoflife.date services.
- Continued source, dependency, container, hardening, SBOM, and dynamic application security checks for the release image.
