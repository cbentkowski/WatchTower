# WatchTower 0.4.0

This release expanded vulnerability intelligence with configurable vendor feeds and safer application matching.

## Highlights

- Added configurable vendor security, release, lifecycle, and advisory feeds.
- Added feed testing, collection, normalization, caching, and application associations.
- Added protections for untrusted feed content and outbound feed requests.
- Added NVD wildcard version-range matching for more accurate applicability decisions.
- Added mounted-file support for SMTP passwords so secrets do not need to be stored in configuration.
