# WatchTower 0.3.0

The initial WatchTower release established a lightweight application vulnerability and lifecycle dashboard.

## Highlights

- Added YAML-backed application and workspace inventory management.
- Added vulnerability monitoring with NVD and CISA known-exploited data.
- Added lifecycle and release tracking for monitored applications.
- Added dashboard status summaries, application details, and manual refresh controls.
- Added email notification support and OpenID Connect authentication.
- Added a container image for straightforward self-hosted deployment.
