# Beacon

Beacon added native HTTPS support and more deliberate notification timing.

## Highlights

- Added optional native HTTPS using mounted certificate and private-key files.
- Added startup validation for TLS configuration, certificate matching, and minimum protocol requirements.
- Added immediate one-time alerts for newly discovered Critical and known-exploited vulnerabilities.
- Added configured delivery windows for High-severity, end-of-life, and repeat notifications.
- Added mounted-secret handling and deployment guidance for safer self-hosted operation.

## Maintenance

- Updated the container build and publishing actions.
- Kept dependency-generated pull requests validation-only.
- Added resource limits to the manual penetration-test workflow.
