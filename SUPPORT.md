# Support

Use the [setup guide](docs/SETUP.md) for installation, upgrades, backup, and
troubleshooting. Use the [user guide](docs/USER_GUIDE.md) for application,
workspace, feed, notification, and access-control guidance.

Open a GitHub issue for a reproducible defect or a focused enhancement request.
Include the WatchTower version, deployment method, relevant configuration with
secrets removed, expected behavior, observed behavior, and useful log excerpts.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md).
